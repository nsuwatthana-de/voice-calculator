# คิดเลขด้วยเสียง

เครื่องคิดเลขที่พูดโจทย์เป็นภาษาไทยได้ แสดงคำตอบและอ่านออกเสียงให้ฟัง ใช้งานบนมือถือได้

- พูดหรือพิมพ์ เช่น "สิบห้าลบเจ็ด", "20% ของ 50", "สามส่วนสี่บวกหนึ่งส่วนสี่", "รากที่สองของ 64", "2 ยกกำลัง 5"
- ทั้งแอปอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่ต้องติดตั้งอะไร
- การรับเสียงใช้ Web Speech API ของเบราว์เซอร์ (Chrome บน Android และคอม, Safari บน iOS) และต้องเปิดผ่าน https

พัฒนาโดย Natthikorn Suwatthana

## สั่งชุดกีฬา

หน้า `uniform.html` ใช้กรอกขนาดเสื้อและกางเกงกีฬาของนักเรียนแต่ละคน สรุปยอดตามขนาด และส่งออกเป็น Excel (.xlsx) หรือภาพ (.png) เพื่อส่งให้ร้าน ข้อมูลเก็บไว้ในเบราว์เซอร์ของเครื่องนั้น
