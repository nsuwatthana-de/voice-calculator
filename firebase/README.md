# เตรียมระบบ Firebase สำหรับสั่งชุดกีฬา

ไฟล์ในโฟลเดอร์นี้ยังไม่ได้ deploy ต้องทำตามขั้นตอนด้านล่างด้วยบัญชี Firebase ของคุณ

## ผังการทำงาน
- **Authentication:** สมาชิกล็อกอินด้วยอีเมล (แนะนำ Email link หรือ Google)
- **Firestore:** เก็บออเดอร์ สมาชิก เบอร์โทร สถานะจ่าย และประวัติการแก้ไข
- **Storage:** เก็บรูปสลิป ไฟล์ชื่อ `slips/{orderId}/{memberId}`
- **links:** ผูกบัญชีผู้ใช้กับสมาชิก 1 คนต่อ 1 ออเดอร์
- **ครู:** ผู้ใช้ที่มี custom claim `teacher=true`

## สิทธิ์ที่กำหนดไว้ในกฎ
| ใคร | อ่าน | แก้ไข |
|---|---|---|
| ครู | ทั้งหมด | ทั้งหมด รวมยอดและสถานะจ่าย |
| สมาชิก | ออเดอร์ที่ผูกไว้ | เฉพาะแถวของตัวเอง: ชื่อ ไซส์ ชื่อหลังเสื้อ เบอร์ สลิป และติ๊กจ่ายแล้ว |
| ทุกคน | — | ประวัติการแก้ไขเพิ่มได้ แก้หรือลบไม่ได้ |

## ขั้นตอนตั้งค่า
1. เข้า https://console.firebase.google.com แล้วสร้างโปรเจกต์ใหม่
2. เปิด **Authentication** → Sign-in method → เปิด Email link (หรือ Google)
3. เปิด **Firestore Database** (โหมด production) และ **Storage**
4. เพิ่ม Web app ใน Project settings แล้วคัดลอก config ไปใส่ใน `firebase-config.js` (คัดลอกจาก `firebase-config.template.js`)
5. ติดตั้ง Firebase CLI และ deploy กฎ
   ```
   npm install -g firebase-tools
   firebase login
   firebase use --add        # เลือกโปรเจกต์ที่สร้าง
   firebase deploy --only firestore:rules,storage
   ```
6. ตั้งครูเป็นผู้ดูแล ทำด้วย Admin SDK ครั้งเดียว (ต้องมี service account key ที่เก็บเป็นความลับ ห้ามใส่ในหน้าเว็บ)
   ```
   admin.auth().setCustomUserClaims(TEACHER_UID, { teacher: true })
   ```
7. เมื่อสมาชิกล็อกอินครั้งแรก ครูสร้างเอกสารใน `links` ชื่อ `{uid}_{orderId}` ที่มีฟิลด์ `memberId` เพื่อผูกบัญชีกับแถวสมาชิก

## ข้อควรรู้
- ข้อมูลส่วนบุคคล (เบอร์โทรและสลิป) จะถูกเก็บไว้บนเซิร์ฟเวอร์ Firebase ควรแจ้งสมาชิกและเปิดให้เฉพาะคนที่เกี่ยวข้อง
- กฎความปลอดภัยยังไม่ได้ทดสอบจริง ควรทดสอบด้วย Firebase Emulator ก่อน deploy ใช้งานจริง
- ประวัติการแก้ไขตอนนี้เขียนจากฝั่งไคลเอนต์ ผู้ใช้ที่ล็อกอินเขียนข้อความใดก็ได้ในประวัติของตัวเอง ถ้าต้องการความเข้มงวด ควรย้ายไปเขียนด้วย Cloud Function
- ยังไม่มีหน้าเว็บที่เชื่อม Firebase ในโฟลเดอร์นี้ จะทำหลังจากตั้งค่าโปรเจกต์เสร็จแล้ว
